xbrowsersync-api-rs

Version {version} · max sync size {max_sync_size} bytes

GET /info

Returns service info: location, maxSyncSize, message, status (0 online, 1 no new syncs, 2 offline), version.

POST /bookmarks

Create a new sync. Body: {"bookmarks": "..."} (v1) or {"version": "..."} (v1.1.3+). Response: {"id", "lastUpdated", "version"}.

GET /bookmarks/:id

Retrieves bookmarks data for a sync: {"bookmarks", "version", "lastUpdated"}.

PUT /bookmarks/:id

Update a sync. v1.1.3+ body: {"bookmarks", "lastUpdated", "version"}; mismatched lastUpdated returns 409. Response: {"lastUpdated"}.

GET /bookmarks/:id/lastUpdated

Returns {"lastUpdated"} for checking remote changes before pulling.

GET /bookmarks/:id/version

Returns {"version"}.

Errors

Error responses use {"code": "ExceptionName", "message": "..."}. Sync IDs are UUIDv4, 32 hex characters without dashes.
